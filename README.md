## 👋 What is XADON AI, really?

Look, there are a ton of WhatsApp bots out there. Most of them are either dead, broken, or a pain to set up.

XADON is different. It's a proper Node.js WhatsApp bot that my guy **Musteqeem** keeps alive and updated. You link it once with a pairing code, and boom — you've got like **250 advertised commands** sitting in your WhatsApp. Group management, AI chat, stickers, media converters, games, search tools, owner controls... the works.

Under the hood it's running on **@musteqeem/baileys** (a maintained Baileys fork) and the whole thing grew out of the **WAPLUS AI** base. Commands load as separate modules, your login session stays saved on disk, and if the connection drops it just reconnects by itself.

Current release is **XADON AI v3**. Heads up — commands can change between updates, so whatever `.menu` shows you inside WhatsApp is always the truth.

### The Autodeployer Script for pterodactly Panel
```bash
/**
 * Pterodactyl bootstrapper for XADON (or any git-backed Node app).
 *
 * Behavior:
 *  - On start: clone the repo (if missing) or pull latest (if exists)
 *  - Install dependencies (npm ci if lockfile present, otherwise npm install)
 *  - Exec the repository start command (default: `node index.js`) and forward logs/signals
 *
 * Configure with environment variables:
 *  - REPO_URL      (default: https://github.com/musteqeem/xadon)
 *  - BRANCH        (default: main)
 *  - APP_DIR       (default: app)           Directory to clone into (relative to script)
 *  - GIT_DEPTH     (default: 1)             Use shallow clone depth (set 0 for full)
 *  - INSTALL_CMD   (optional)               Custom install command (overrides npm logic)
 *  - START_CMD     (default: node index.js) Command to launch the app inside APP_DIR
 *  - SKIP_INSTALL  (true/false)             If true, skip dependency install
 *
 * Usage on Pterodactyl:
 *  - Upload this file as your server's "index.js" startup file.
 *  - Set the server startup command to: `node index.js`
 *  - Optional: set environment variables in the panel to customize repo/branch/start command.
 */

const { spawn } = require('child_process');
const fs = require('fs');
const path = require('path');

const REPO_URL = process.env.REPO_URL || 'https://github.com/musteqeem/xadon';
const BRANCH = process.env.BRANCH || 'main';
const APP_DIR = process.env.APP_DIR || 'app';
const GIT_DEPTH = process.env.GIT_DEPTH === '0' ? 0 : Number(process.env.GIT_DEPTH || 1);
const INSTALL_CMD = process.env.INSTALL_CMD || '';
const START_CMD = process.env.START_CMD || 'node index.js';
const SKIP_INSTALL = (process.env.SKIP_INSTALL || '').toLowerCase() === 'true';

function log(...args) { console.log(new Date().toISOString(), ...args); }

function run(cmd, args = [], opts = {}) {
  return new Promise((resolve, reject) => {
    log(`> ${cmd} ${args.join(' ')}`);
    const p = spawn(cmd, args, { stdio: 'inherit', shell: false, ...opts });
    p.on('error', (err) => reject(err));
    p.on('exit', (code, sig) => {
      if (sig) return reject(new Error(`Process killed by signal ${sig}`));
      if (code === 0) resolve(code);
      else reject(new Error(`Exit code ${code}`));
    });
  });
}

async function sh(command, opts = {}) {
  // run via shell to allow complex commands
  return new Promise((resolve, reject) => {
    log(`$ ${command}`);
    const p = spawn(command, { stdio: 'inherit', shell: true, ...opts });
    p.on('error', (err) => reject(err));
    p.on('exit', (code, sig) => {
      if (sig) return reject(new Error(`Killed by signal ${sig}`));
      if (code === 0) resolve(code);
      else reject(new Error(`Exit code ${code}`));
    });
  });
}

async function exists(p) { try { await fs.promises.access(p); return true; } catch { return false; } }

async function ensureGit() {
  try {
    await run('git', ['--version']);
  } catch (err) {
    throw new Error('git is required but not available: ' + err.message);
  }
}

async function cloneRepo(dest) {
  const depthArg = GIT_DEPTH && GIT_DEPTH > 0 ? ['--depth', String(GIT_DEPTH)] : [];
  const args = ['clone', ...depthArg, '--branch', BRANCH, REPO_URL, dest].filter(Boolean);
  await run('git', args);
}

async function updateRepo(dest) {
  // Prefer a conservative pull/fast-forward. If pull fails, fall back to fetch+reset.
  try {
    await run('git', ['-C', dest, 'fetch', 'origin', BRANCH, '--depth', String(GIT_DEPTH || 1)]);
    await run('git', ['-C', dest, 'reset', '--hard', 'FETCH_HEAD']);
  } catch (err) {
    log('fetch/reset failed, trying pull...', err.message);
    await run('git', ['-C', dest, 'pull', 'origin', BRANCH]);
  }
}

async function installDeps(dest) {
  if (SKIP_INSTALL) {
    log('SKIP_INSTALL=true, skipping dependency installation');
    return;
  }
  if (INSTALL_CMD) {
    log('Running custom install command:', INSTALL_CMD);
    await sh(INSTALL_CMD, { cwd: dest });
    return;
  }
  const lockfile = await exists(path.join(dest, 'package-lock.json'));
  if (lockfile) {
    log('Found package-lock.json, running: npm ci');
    await run('npm', ['ci'], { cwd: dest });
  } else {
    log('No lockfile found, running: npm install');
    await run('npm', ['install'], { cwd: dest });
  }
}

function spawnApp(dest) {
  // Use shell so START_CMD can contain complex commands; run in cwd=dest
  log('Starting application with:', START_CMD);
  const child = spawn(START_CMD, { shell: true, cwd: dest, stdio: 'inherit' });

  // Forward signals to child
  const forward = (sig) => {
    log(`Forwarding ${sig} to child`);
    try { child.kill(sig); } catch (e) { /* ignore */ }
  };
  process.on('SIGINT', () => forward('SIGINT'));
  process.on('SIGTERM', () => forward('SIGTERM'));
  process.on('SIGHUP', () => forward('SIGHUP'));

  child.on('exit', (code, signal) => {
    if (signal) {
      log(`Child exited due to signal ${signal}`);
      process.exit(1);
    } else {
      log(`Child exited with code ${code}`);
      // Exit with the child's exit code so Pterodactyl can handle restarts.
      process.exit(typeof code === 'number' ? code : 0);
    }
  });

  child.on('error', (err) => {
    log('Failed to start child process:', err);
    process.exit(1);
  });
}

(async () => {
  try {
    const base = process.cwd();
    const dest = path.resolve(base, APP_DIR);

    log('Bootstrap starting');
    log('REPO_URL=', REPO_URL);
    log('BRANCH=', BRANCH);
    log('APP_DIR=', dest);
    log('GIT_DEPTH=', GIT_DEPTH);
    log('START_CMD=', START_CMD);

    await ensureGit();

    const hasDir = await exists(dest);
    if (!hasDir) {
      log('App directory not found — cloning repository...');
      await cloneRepo(dest);
    } else {
      // quick sanity check: is it a git repo?
      const isGit = await (async () => {
        try {
          await run('git', ['-C', dest, 'rev-parse', '--is-inside-work-tree']);
          return true;
        } catch { return false; }
      })();

      if (!isGit) {
        log('Directory exists but is not a git repository. Renaming and re-cloning.');
        const back = `${dest}.backup.${Date.now()}`;
        await fs.promises.rename(dest, back);
        await cloneRepo(dest);
      } else {
        log('Repository found — updating to latest on branch', BRANCH);
        await updateRepo(dest);
      }
    }

    // install deps
    try {
      await installDeps(dest);
    } catch (err) {
      log('Dependency installation failed:', err.message);
      log('You can set SKIP_INSTALL=true to skip install in environments where dependencies are preinstalled.');
      // continue to attempt to start anyway
    }

    // finally start the app inside dest
    spawnApp(dest);
  } catch (err) {
    console.error('Bootstrap failed:', err && err.message ? err.message : err);
    process.exit(1);
  }
})();
```

## 🔗 How to Link WhatsApp (pairing tutorial)

This trips up most first-timers, so let's go slow:

1. **Start the bot** (`npm start`). Watch the terminal/console — it'll print a pairing code like `XAD1-ON23`. If you set `PAIRING_NUMBER` in `.env`, it requests the code automatically.
2. **On your phone**, open WhatsApp → **⋮ menu → Linked devices → Link a device**. If it offers **"Link with phone number instead"**, tap that.
3. **Type in the code** from the console. Approve it.
4. **Wait for "bot is online"** in the logs. Your login files now live in `session/` (or whatever `SESSION_DIR` says). Keep that folder **private and persistent**.

**Tips that save headaches:**

- 🖥️ **On your own laptop?** You can skip `PAIRING_NUMBER` and just type the number when it asks.
- ☁️ **On a host with no terminal input?** You MUST set `PAIRING_NUMBER` in the panel's env vars *before* starting.
- ⏱️ **Code expired?** Just restart, get a fresh one, be quick.
- 🔒 **Treat `session/` like a password.** Anyone with those files can hijack your session. Never commit it, never send it to anyone, never screenshot it.

## 🤖 The Autodeployer Script (Pterodactyl / any panel)

Save this as `index.js` in your panel. Set startup to `node index.js`. It clones the repo, installs deps, and starts the bot for you — no manual zip uploads.

<details>
<summary><b>📜 Click to expand the full script</b></summary>

```js
#!/usr/bin/env node
/**
 * Pterodactyl bootstrapper for XADON (or any git-backed Node app).
 *
 * Behavior:
 *  - On start: clone the repo (if missing) or pull latest (if exists)
 *  - Install dependencies (npm ci if lockfile present, otherwise npm install)
 *  - Exec the repository start command (default: `node index.js`) and forward logs/signals
 *
 * Configure with environment variables:
 *  - REPO_URL      (default: https://github.com/musteqeem/xadon)
 *  - BRANCH        (default: main)
 *  - APP_DIR       (default: app)           Directory to clone into (relative to script)
 *  - GIT_DEPTH     (default: 1)             Use shallow clone depth (set 0 for full)
 *  - INSTALL_CMD   (optional)               Custom install command (overrides npm logic)
 *  - START_CMD     (default: node index.js) Command to launch the app inside APP_DIR
 *  - SKIP_INSTALL  (true/false)             If true, skip dependency install
 *
 * Usage on Pterodactyl:
 *  - Upload this file as your server's "index.js" startup file.
 *  - Set the server startup command to: `node index.js`
 *  - Optional: set environment variables in the panel to customize repo/branch/start command.
 */

const { spawn } = require('child_process');
const fs = require('fs');
const path = require('path');

const REPO_URL = process.env.REPO_URL || 'https://github.com/musteqeem/xadon';
const BRANCH = process.env.BRANCH || 'main';
const APP_DIR = process.env.APP_DIR || 'app';
const GIT_DEPTH = process.env.GIT_DEPTH === '0' ? 0 : Number(process.env.GIT_DEPTH || 1);
const INSTALL_CMD = process.env.INSTALL_CMD || '';
const START_CMD = process.env.START_CMD || 'node index.js';
const SKIP_INSTALL = (process.env.SKIP_INSTALL || '').toLowerCase() === 'true';

function log(...args) { console.log(new Date().toISOString(), ...args); }

function run(cmd, args = [], opts = {}) {
  return new Promise((resolve, reject) => {
    log(`> ${cmd} ${args.join(' ')}`);
    const p = spawn(cmd, args, { stdio: 'inherit', shell: false, ...opts });
    p.on('error', (err) => reject(err));
    p.on('exit', (code, sig) => {
      if (sig) return reject(new Error(`Process killed by signal ${sig}`));
      if (code === 0) resolve(code);
      else reject(new Error(`Exit code ${code}`));
    });
  });
}

async function sh(command, opts = {}) {
  return new Promise((resolve, reject) => {
    log(`$ ${command}`);
    const p = spawn(command, { stdio: 'inherit', shell: true, ...opts });
    p.on('error', (err) => reject(err));
    p.on('exit', (code, sig) => {
      if (sig) return reject(new Error(`Killed by signal ${sig}`));
      if (code === 0) resolve(code);
      else reject(new Error(`Exit code ${code}`));
    });
  });
}

async function exists(p) { try { await fs.promises.access(p); return true; } catch { return false; } }

async function ensureGit() {
  try {
    await run('git', ['--version']);
  } catch (err) {
    throw new Error('git is required but not available: ' + err.message);
  }
}

async function cloneRepo(dest) {
  const depthArg = GIT_DEPTH && GIT_DEPTH > 0 ? ['--depth', String(GIT_DEPTH)] : [];
  const args = ['clone', ...depthArg, '--branch', BRANCH, REPO_URL, dest].filter(Boolean);
  await run('git', args);
}

async function updateRepo(dest) {
  try {
    await run('git', ['-C', dest, 'fetch', 'origin', BRANCH, '--depth', String(GIT_DEPTH || 1)]);
    await run('git', ['-C', dest, 'reset', '--hard', 'FETCH_HEAD']);
  } catch (err) {
    log('fetch/reset failed, trying pull...', err.message);
    await run('git', ['-C', dest, 'pull', 'origin', BRANCH]);
  }
}

async function installDeps(dest) {
  if (SKIP_INSTALL) {
    log('SKIP_INSTALL=true, skipping dependency installation');
    return;
  }
  if (INSTALL_CMD) {
    log('Running custom install command:', INSTALL_CMD);
    await sh(INSTALL_CMD, { cwd: dest });
    return;
  }
  const lockfile = await exists(path.join(dest, 'package-lock.json'));
  if (lockfile) {
    log('Found package-lock.json, running: npm ci');
    await run('npm', ['ci'], { cwd: dest });
  } else {
    log('No lockfile found, running: npm install');
    await run('npm', ['install'], { cwd: dest });
  }
}

function spawnApp(dest) {
  log('Starting application with:', START_CMD);
  const child = spawn(START_CMD, { shell: true, cwd: dest, stdio: 'inherit' });

  const forward = (sig) => {
    log(`Forwarding ${sig} to child`);
    try { child.kill(sig); } catch (e) { /* ignore */ }
  };
  process.on('SIGINT', () => forward('SIGINT'));
  process.on('SIGTERM', () => forward('SIGTERM'));
  process.on('SIGHUP', () => forward('SIGHUP'));

  child.on('exit', (code, signal) => {
    if (signal) {
      log(`Child exited due to signal ${signal}`);
      process.exit(1);
    } else {
      log(`Child exited with code ${code}`);
      process.exit(typeof code === 'number' ? code : 0);
    }
  });

  child.on('error', (err) => {
    log('Failed to start child process:', err);
    process.exit(1);
  });
}

(async () => {
  try {
    const base = process.cwd();
    const dest = path.resolve(base, APP_DIR);

    log('Bootstrap starting');
    log('REPO_URL=', REPO_URL);
    log('BRANCH=', BRANCH);
    log('APP_DIR=', dest);
    log('GIT_DEPTH=', GIT_DEPTH);
    log('START_CMD=', START_CMD);

    await ensureGit();

    const hasDir = await exists(dest);
    if (!hasDir) {
      log('App directory not found — cloning repository...');
      await cloneRepo(dest);
    } else {
      const isGit = await (async () => {
        try {
          await run('git', ['-C', dest, 'rev-parse', '--is-inside-work-tree']);
          return true;
        } catch { return false; }
      })();

      if (!isGit) {
        log('Directory exists but is not a git repository. Renaming and re-cloning.');
        const back = `${dest}.backup.${Date.now()}`;
        await fs.promises.rename(dest, back);
        await cloneRepo(dest);
      } else {
        log('Repository found — updating to latest on branch', BRANCH);
        await updateRepo(dest);
      }
    }

    try {
      await installDeps(dest);
    } catch (err) {
      log('Dependency installation failed:', err.message);
      log('You can set SKIP_INSTALL=true to skip install in environments where dependencies are preinstalled.');
    }

    spawnApp(dest);
  } catch (err) {
    console.error('Bootstrap failed:', err && err.message ? err.message : err);
    process.exit(1);
  }
})();
```

## 🧠 AI Setup Tutorial (Groq / Gemini / OpenAI)

No key = AI commands will fail politely. Here's how to fix that:

1. **Pick ONE provider.** Groq is fast + generous free tier (great default). Gemini is solid too. OpenAI works if you already pay.
2. **Get a key** from their site (Groq console / Google AI Studio / OpenAI dashboard).
3. **Add it to `.env` or panel env:**
   ```dotenv
   AI_PROVIDER=groq
   GROQ_API_KEY=gsk_your_key_here
   ```
   Or for Gemini:
   ```dotenv
   AI_PROVIDER=gemini
   GEMINI_API_KEY=your_key_here
   ```
4. **Restart the bot**, then test:
   ```text
   .ai Write a funny birthday message for my brother
   ```
5. **Broke?** Check: right provider name? key pasted fully with no spaces? quota left? internet ok? Try `AI_PROVIDER=auto` to let it fall back.

> Never paste keys in GitHub issues, chats, or screenshots. If you leak one, revoke it immediately and make a new one.

## 🛡️ Security First (read this)

No README can promise "unbannable" — anyone who does is lying. Do this instead:

- **🔢 Protect your number:** use a spare number. Unofficial automation can get restricted. Don't spam, don't bulk-message strangers.
- **📁 Protect `session/`:** not in git, not in backups people can see, not in screenshots. Leaked? Unlink the device in WhatsApp → fresh session.
- **🔑 Protect keys:** env vars / secret manager only. No keys in commits, issues, logs, or screenshots. Leaked = rotate immediately.
- **🌐 Protect the panel:** don't expose pairing/control pages to the whole internet. Firewall it, keep it private, use HTTPS/reverse proxy if remote.
- **🤝 Don't be annoying:** no spam, no scraping, no auto-adding people. Keep it human-directed and legal.
- **📦 Deploy from YOUR fork/branch.** Review updates + dep changes. Keep Node + deps current, install from lockfile.
- **💾 Back up smart:** private encrypted backup of config/assets. Test that redeploys don't nuke `session/`.
- **1️⃣ One process per session.** Two copies fighting over one session = logouts and weirdness.
- **👮 Least privilege.** Bot only gets the group powers it actually needs. Owner commands stay owner-only.

Business-critical stuff? Use the [official WhatsApp Business Platform](https://developers.facebook.com/docs/whatsapp/). Seriously.

## 🧰 Troubleshooting (fix it fast)

| Symptom | What to check |
|---|---|
| `npm` / Node version errors | Node 20+ selected? Installed from `package.json` / lockfile? |
| `Cannot find module ...` | In repo root? `package.json` present? Did host finish installing deps? |
| No pairing code | `PAIRING_NUMBER` digits-only + international format? Hosts can't do interactive input — set the env first |
| Code rejected | Get a fresh code, link the right account, be quick. Don't share the code |
| Re-pairs every restart | `SESSION_DIR` persistent? Deploys wiping `session/`? Fix storage/volume |
| Keeps reconnecting | Network? WhatsApp down? Another process using same session? Re-pair only if logged out |
| Online but ignores commands | Prefix right? `MODE` public? Bot admin (for group cmds)? Owner number right? Try `.menu` + `.ping` |
| AI fails | Provider + valid key set? Quota left? Network? Try `AI_PROVIDER=auto` |
| Media command fails | File type/size ok? Host RAM/disk ok? Deps installed? External service up? |
| Panel/port dead | `PORT` matches host's expected port? Host allows panel access? Don't expose pairing publicly |

Asking for help? Include: Node version, host, logs (secrets removed), what command/step broke, minimal repro. **Never share `.env`, codes, or session files.**
